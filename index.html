Каталог програмних модулів

Демонстраційний огляд компонентів архітектури SPA на чистому JavaScript.

Core

DOM Routing Engine

Перемикання секцій шляхом модифікації CSS-класів видимості без перезавантаження сторінки.

State

Global State Monitor

Збереження життєвого циклу JavaScript-скриптів, активних таймерів та відтворення медіафайлів.

Performance

Zero Network Reload

Відсутність повторних HTTP-запитів GET за новими HTML-структурами при навігації.

Специфікація та Архітектура

Порівняльний аналіз архітектурних моделей веб-додатків.

Характеристика MPA (Multi-Page App) SPA (Single-Page App)
Рендеринг HTML На сервері під час кожного переходу Одноразово базовий каркас, далі DOM-модифікація
Перезавантаження сторінки Повне перезавантаження при кожному переході Без перезавантаження (Zero Reload)
Глобальний стан (State) Втрачається/скидається при кожному запиті Зберігається неперервно в пам'яті браузера
Мережевий трафік Повторне завантаження розмітки HTML Лише сирі дані (JSON/REST API) при потребі
